# EduCore: Intelligent Campus Management System

EduCore is a next-generation academic administration and student engagement platform powered by AI. It bridges the gap between traditional management systems and modern AI-driven educational tools.

## 🚀 Key Features

### 🎓 For Students
- **AI Study Agent**: Personalized learning assistant that can explain concepts, summarize materials, and generate interactive quizzes.
- **Smart Attendance**: Real-time tracking with visual insights into academic progress.
- **Interactive Timetables**: Dynamic scheduling with built-in break optimization.

### 🏫 For Faculty
- **Seamless Document Ingestion**: Glassmorphism-styled upload interface for syllabus and study materials.
- **AI-Powered Analytics**: Insight into student performance and engagement metrics.
- **Leave Management**: Simplified approval workflows with real-time status tracking.

### 👔 For Administrators
- **Command Center**: Campus-wide KPIs and behavioral risk matrices.
- **Behavioral Risk Matrix**: Proactive identification of at-risk students using attendance and engagement data.
- **Neural Insights**: AI-detected patterns in campus-wide educational engagement.
- **Data Portability**: Professional CSV reporting for administrative oversight.

## 🛠 Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Framer Motion
- **Visualization**: Recharts (Customized for professional academic reporting)
- **Backend**: Supabase (PostgreSQL, Auth, Real-time)
- **AI Engine**: Gemini 1.5 / NVIDIA NIM (Integrated for study assistance)

## 🎨 Design System
EduCore uses a premium, high-contrast design language featuring:
- **Glassmorphism**: Modern, translucent UI elements.
- **Professional Palette**: Slate, Indigo, and Emerald accents.
- **Dynamic Feedback**: Micro-animations and responsive chart containers.

## 📦 Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Set up environment variables for Supabase and AI APIs.
4. Run development server: `npm run dev`.
